# Assignment-1

## Task 1: Perform Basic Mathematical Operations

### Problem Description
This program performs basic mathematical operations on two numbers entered by the user.

### Functionality
The program:
1. Takes two numbers as input from the user.
2. Performs the following operations:
   - Addition
   - Subtraction
   - Multiplication
   - Division
3. Displays the result of each operation on the screen.

### Expected Output (Example)
If the user enters:
- First number: 10
- Second number: 5

The output will be:
Enter the first number-5
Enter the second number-10
Addition: 15
Subtraction: -5
Multiplication: 50
Divison: 0.5






## Task 2: Create a Personalized Greeting

### Problem Description
This program creates a personalized greeting message for the user.

### Functionality
The program:
1. Takes the user's first name and last name as input.
2. Concatenates them to form the full name.
3. Prints a greeting message using the full name.

### Expected Output (Example)
If the user enters:
- First name: John
- Last name: Doe

The output will be:
Enter your first name:John
Enter your second name:Doe
Hello, John Doe ! Welcome to the python program.
